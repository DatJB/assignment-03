# Assignment 03 - Introduction to Deep Learning

## 1. Chẩn đoán bệnh tiểu đường

Notebook xây dựng bài toán **phân loại bệnh tiểu đường** và so sánh 4 mô hình:

- Logistic Regression
- Decision Tree
- Random Forest
- Deep Learning MLP tự viết bằng NumPy

Các mô hình được đánh giá bằng Accuracy, Precision, Recall, F1, ROC-AUC và PR-AUC.

---

## 2. Dự đoán giá nhà

Notebook giải quyết bài toán **Regression** dự đoán giá bất động sản tại Hà Nội và TP. Hồ Chí Minh.

Bốn mô hình được sử dụng:

- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- Deep Learning MLP tự viết bằng NumPy

Các metrics gồm MAE, MSE, RMSE và R².

## 3. E-commerce Customer-Interest Discovery

Notebook dự đoán khách hàng có **recommend sản phẩm** hay không dựa trên thông tin khách hàng, loại sản phẩm và nội dung review.

Bốn mô hình được so sánh:

- Logistic Regression
- Decision Tree
- Random Forest
- Deep Learning MLP tự viết bằng NumPy

Văn bản được biểu diễn bằng TF-IDF. Các mô hình được đánh giá bằng Accuracy, Precision, Recall, F1, ROC-AUC và MSE.
